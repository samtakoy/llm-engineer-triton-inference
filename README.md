
> ⚠️ **Важно про место на диске:** Для сборки временно скачивается донорский образ ONNX (~20 ГБ). После успешного завершения сборки вы можете безопасно удалить его, чтобы освободить место:
> ```bash
> docker image rm hubimage/nvcr-io-nvidia-tritonserver:25.05-py3
> ```

Либо изначально собирать образ так:
> docker build --prune -t triton-hw .
